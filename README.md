## 🚀 Overview

The **Cyber Security Toolkit** is a Python-based integrated security solution designed to identify, analyze, and mitigate web and network vulnerabilities.

This project showcases hands-on expertise in **ethical hacking, vulnerability assessment, network scanning, and security automation**, making it highly relevant for roles like **SOC Analyst, Cybersecurity Analyst, and Penetration Tester**.

It simulates real-world security operations by combining multiple cybersecurity techniques into a **single unified platform**.

---

## 🎯 Key Objectives

* Detect web vulnerabilities (SQL Injection, XSS)
* Perform **port scanning** to identify open services
* Crawl and analyze website links
* Discover hidden directories (Directory Brute Force)
* Extract network/system information
* Monitor live network traffic
* Automate penetration testing basics

---

## 🛠️ Features

### 🔍 1. Vulnerability Scanner

* Detects **SQL Injection**
* Identifies **Cross-Site Scripting (XSS)**
* Helps secure web applications

---

### 🔗 2. Link Crawler (Web Crawling)

* Extracts all links from a target website
* Discovers hidden or unlinked pages
* Helps in **attack surface mapping**

---

### 📂 3. Directory Scanner (Brute Force)

* Finds hidden directories like `/admin`, `/login`, `/dashboard`
* Uses wordlists to discover sensitive paths
* Helps identify **exposed endpoints**

---

### 🚪 4. Port Scanner

* Scans system for **open ports**
* Identifies commonly used ports:

  * 21 (FTP)
  * 22 (SSH)
  * 80 (HTTP)
  * 443 (HTTPS)
* Useful for **network vulnerability assessment**

---

### 🌐 5. Network Information Scanner

* Retrieves:

  * IP address
  * Hostname
  * Open ports
  * Network details
* Helps understand system exposure

---

### 📡 6. Network Sniffer (Packet Monitoring)

* Captures live traffic using **Scapy**
* Analyzes packets in real-time
* Helps detect suspicious activity

---

### 🔗 7. URL & Data Analyzer

* Parses URLs
* Detects suspicious patterns
* Identifies potential malicious inputs
